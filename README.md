# Enterprise CI/CD Platform

Proyecto demostrativo orientado a la implementación de una plataforma profesional de integración y entrega continua.

## Objetivo

Demostrar conocimientos y experiencia en:

- Desarrollo de aplicaciones
- Arquitectura de software
- Docker y Docker Compose
- Jenkins
- Integración y entrega continua
- NGINX
- Java y Spring Boot
- Python y FastAPI
- React
- Git y GitHub
- Kubernetes
- Terraform
- SonarQube
- Monitoreo

## Arquitectura

La plataforma estará compuesta inicialmente por:

- Frontend desarrollado en React
- API desarrollada en Java con Spring Boot
- API desarrollada en Python con FastAPI
- NGINX como reverse proxy
- Docker Compose para la ejecución local
- Jenkins para CI/CD
